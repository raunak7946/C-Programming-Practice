# C Programming Practice

This repository contains my C programming practice and projects.

## Scrabble Score Calculator

I created a C program that takes a word from two players, calculates the Scrabble score of each word, and compares their scores to determine the winner or if the game ends in a tie.

The program assigns points to each letter, handles both uppercase and lowercase letters, and uses a function to calculate the total score of each word.
